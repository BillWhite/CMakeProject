CMakeProject
============

A cookiecutter template for C++ projects with CMake and gmock

This depends on cookiecutter and gmock 1.7.0.

Installation.

1. Install cookiecutter.
1. Install gmock somewhere, maybe in $HOME/src/gmock-1.7.0.
1. cookiecutter git@github.com:BillWhite/CMakeProject.git
   and answer the questions.
